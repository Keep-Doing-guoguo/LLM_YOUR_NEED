# 图像分割基础：语义分割、实例分割、全景分割与通用分割

图像分割是计算机视觉中比目标检测更细粒度的任务。目标检测通常回答：

```text
图中有什么物体？它们的大致位置在哪里？
```

图像分割进一步回答：

```text
每个像素属于什么区域？
这个区域是不是某个独立对象？
多个对象、背景和语义类别如何同时表达？
```

因此，分割任务的输出不再只是矩形框，而是 mask，也就是像素级区域。

## 一、先理解一个核心问题

不同分割任务的区别，本质上来自三个问题：

| 问题 | 含义 |
|---|---|
| 是否关心类别 | 这个像素是人、车、路面，还是天空 |
| 是否区分个体 | 两个人是否要分成 person-1 和 person-2 |
| 是否覆盖整张图 | 背景、道路、天空这些 stuff 是否也要标出来 |

根据这三个问题，可以得到常见的几类分割：

| 任务 | 关心类别 | 区分个体 | 覆盖整图 |
|---|---|---|---|
| 语义分割 | 是 | 否 | 通常是 |
| 实例分割 | 是 | 是 | 通常只关注目标实例 |
| 全景分割 | 是 | 是，对 thing 类 | 是 |
| 通用分割 | 不固定 | 取决于提示和模型 | 取决于任务 |

更口语化地记，可以先这样理解：

| 任务 | 处理范围 | 是否能计数 |
|---|---|---|
| 语义分割 | 通常整图都处理，包含 thing 和 stuff | 不能可靠计数，因为不区分同类个体 |
| 实例分割 | 主要处理 thing，也就是人、车、动物、商品这类可数目标 | 可以计数，因为每个实例有独立 mask |
| 全景分割 | 整图都处理；thing 区分实例，stuff 只标区域 | thing 可以计数，stuff 不计数 |
| 通用分割 | 可以处理多种目标和区域，范围由提示或模型能力决定 | 如果输出的是独立实例 mask，就可以计数；如果只是区域 mask，就不等于计数 |

所以你说的“语义分割都处理，但是不会计数”和“实例分割只处理 thing，会计数”是对的；“通用分割全部处理，但是会计数”需要加一个条件：通用分割要在输出实例级 mask 时才适合计数。

## 二、语义分割 Semantic Segmentation

语义分割的目标是：给图像中的每个像素分配一个语义类别。

例如一张街景图：

```text
道路像素 -> road
天空像素 -> sky
行人像素 -> person
车辆像素 -> car
建筑像素 -> building
```

语义分割不区分同类物体的不同个体。

如果图中有 3 个人，语义分割只会输出：

```text
这些像素都属于 person 类
```

不会输出：

```text
person-1
person-2
person-3
```

### 输出形式

语义分割的输出通常是一张类别图：

```text
H x W
每个像素位置存一个 class_id
```

也可以理解为：

```text
输入图像: H x W x 3
输出标签: H x W
```

示例：

```text
0 = background
1 = road
2 = person
3 = car
4 = sky
```

### 适合场景

| 场景 | 原因 |
|---|---|
| 自动驾驶道路理解 | 需要知道道路、车道、天空、建筑等区域 |
| 医学图像器官分割 | 常常只关心器官类别区域 |
| 遥感土地覆盖分类 | 关注水体、建筑、植被、道路等类别 |
| 工业缺陷区域分割 | 关注缺陷像素区域 |

### 代表模型

| 模型 | 特点 |
|---|---|
| FCN | 早期端到端语义分割模型 |
| U-Net | 医学图像分割常用，编码器-解码器结构 |
| DeepLab | 空洞卷积和 ASPP，多尺度上下文强 |
| PSPNet | 金字塔池化增强全局上下文 |
| SegFormer | Transformer 风格语义分割模型 |

### 常用指标

| 指标 | 说明 |
|---|---|
| Pixel Accuracy | 像素分类准确率 |
| mIoU | 各类别 IoU 的平均值，最常用 |
| Dice | 医学分割中常见，关注区域重叠 |

## 三、实例分割 Instance Segmentation

实例分割的目标是：找到图像中的每个目标实例，并为每个实例生成独立 mask。

它同时回答两个问题：

```text
这是什么类别？
这是第几个独立对象？
```

如果图中有 3 个人，实例分割会输出：

```text
person-1 mask
person-2 mask
person-3 mask
```

每个人都有独立的 mask，即使他们属于同一个类别。

### 输出形式

实例分割通常输出一个实例列表：

```text
[
  {class: person, score: 0.96, mask: mask_1, bbox: box_1},
  {class: person, score: 0.93, mask: mask_2, bbox: box_2},
  {class: car, score: 0.91, mask: mask_3, bbox: box_3}
]
```

与语义分割不同，实例分割不是只输出一张 class_id 图，而是输出多个对象 mask。

### 与目标检测的关系

实例分割可以看作：

```text
目标检测 + 每个目标的像素级 mask
```

目标检测输出框：

```text
person bbox
```

实例分割输出框和轮廓区域：

```text
person bbox + person mask
```

### 适合场景

| 场景 | 原因 |
|---|---|
| 人、车、商品计数 | 需要区分每个独立对象 |
| 工业抓取 | 机械臂需要知道每个物体的精确轮廓 |
| 自动标注 | 需要生成每个目标的 mask |
| 电商抠图 | 每个商品要单独分离 |

### 代表模型

| 模型 | 特点 |
|---|---|
| Mask R-CNN | 经典两阶段实例分割模型 |
| YOLACT | 实时实例分割思路 |
| SOLO / SOLOv2 | 按位置划分实例 |
| YOLOv8-Seg | YOLO 系列实例分割工程方案 |
| Mask2Former | 可统一处理语义、实例、全景分割 |

### 常用指标

| 指标 | 说明 |
|---|---|
| Mask AP | COCO 实例分割核心指标 |
| AP50 / AP75 | mask IoU 阈值为 0.5 / 0.75 的 AP |
| AR | 平均召回率 |

## 四、全景分割 Panoptic Segmentation

全景分割的目标是：整张图的每个像素都要有语义类别，同时可数物体还要区分实例。

它可以理解为：

```text
语义分割 + 实例分割
```

但这句话要更准确一点：

```text
stuff 类：只做语义分割
thing 类：做实例分割
```

### Thing 与 Stuff

全景分割中经常区分 thing 和 stuff：

| 类型 | 含义 | 示例 |
|---|---|---|
| thing | 可数对象，有独立实例 | person、car、dog、bicycle |
| stuff | 不可数背景或区域 | sky、road、grass、wall、water |

例如街景图：

```text
person-1
person-2
car-1
road
sky
building
tree
```

其中 person、car 要区分实例；road、sky、building 通常不区分第几个。

### 输出形式

全景分割通常输出一张 panoptic map：

```text
H x W
每个像素存 segment_id
```

同时还会有一个映射表：

```text
segment_id -> class_id, instance_id, isthing
```

例如：

```text
17 -> class=person, instance=1, isthing=True
18 -> class=person, instance=2, isthing=True
23 -> class=road, instance=None, isthing=False
24 -> class=sky, instance=None, isthing=False
```

### 适合场景

| 场景 | 原因 |
|---|---|
| 自动驾驶场景理解 | 既要知道道路天空，也要区分车辆行人 |
| 机器人导航 | 需要完整环境理解 |
| 城市场景解析 | 同时分析背景区域和独立目标 |
| 高级图像理解 | 需要像素级完整结构 |

### 代表模型

| 模型 | 特点 |
|---|---|
| Panoptic FPN | 早期全景分割框架 |
| UPSNet | 统一语义和实例分割分支 |
| MaskFormer | 用 mask classification 统一语义和全景 |
| Mask2Former | 进一步统一语义、实例、全景分割 |

### 常用指标

| 指标 | 说明 |
|---|---|
| PQ | Panoptic Quality，全景分割核心指标 |
| SQ | Segmentation Quality，分割质量 |
| RQ | Recognition Quality，识别质量 |

PQ 可以粗略理解为：

```text
PQ = 分割准不准 x 识别对不对
```

## 五、通用分割 General / Universal Segmentation

通用分割不是一个像语义分割、实例分割、全景分割那样严格固定的数据集任务。它更多表示一种模型能力：

```text
模型能根据不同提示、不同类别体系、不同任务要求，生成需要的 mask。
```

现在说“通用分割”，通常会涉及几类能力：

| 能力 | 含义 | 代表方向 |
|---|---|---|
| Promptable Segmentation | 根据点、框、粗 mask 等提示分割 | SAM |
| Open-Vocabulary Segmentation | 分割训练类别之外的开放词汇对象 | CLIP + segmentation |
| Referring Segmentation | 根据文本描述分割指定对象 | “左边穿红衣服的人” |
| Universal Segmentation | 一个模型统一语义、实例、全景任务 | Mask2Former |
| Foundation Segmentation | 大规模预训练，迁移到多种分割场景 | SAM / SAM2 |

### SAM 属于哪种分割

SAM 的核心不是传统意义上的语义分割或实例分割，而是 promptable segmentation。

它输入：

```text
图像 + 提示
```

提示可以是：

```text
点
框
已有 mask
```

输出：

```text
与提示对应的 mask
```

SAM 本身通常不直接告诉你这个 mask 是 person 还是 car。它更擅长“把区域切出来”，类别识别需要额外模型或系统配合。

### 通用分割与传统分割的区别

| 对比项 | 传统分割 | 通用分割 |
|---|---|---|
| 类别集合 | 通常固定 | 可开放或由提示决定 |
| 输入形式 | 图像 | 图像 + 点/框/文本/mask 等提示 |
| 输出目标 | 固定任务标签 | 按需求输出 mask |
| 训练方式 | 数据集监督为主 | 大规模预训练 + 迁移 |
| 代表模型 | U-Net、DeepLab、Mask R-CNN | SAM、SAM2、Mask2Former、开放词汇分割模型 |

## 六、四类分割任务对比

| 维度 | 语义分割 | 实例分割 | 全景分割 | 通用分割 |
|---|---|---|---|---|
| 是否分类 | 是 | 是 | 是 | 不一定 |
| 是否区分实例 | 否 | 是 | thing 类区分 | 取决于提示 |
| 是否覆盖整图 | 是 | 通常否 | 是 | 取决于任务 |
| 输出形式 | 每像素 class_id | 多个实例 mask | panoptic map + segment info | 一个或多个提示相关 mask |
| 典型指标 | mIoU / Dice | Mask AP | PQ | 依任务而定 |
| 代表模型 | FCN、U-Net、DeepLab、SegFormer | Mask R-CNN、YOLOv8-Seg | Panoptic FPN、Mask2Former | SAM、SAM2、Mask2Former |

## 七、用一张图来理解

假设图中有：

```text
2 个人
1 辆车
道路
天空
建筑
```

语义分割输出：

```text
person 区域
car 区域
road 区域
sky 区域
building 区域
```

实例分割输出：

```text
person-1 mask
person-2 mask
car-1 mask
```

通常不输出 road、sky、building 这些背景 stuff 的完整语义图。

全景分割输出：

```text
person-1 mask
person-2 mask
car-1 mask
road 区域
sky 区域
building 区域
```

通用分割输出取决于提示：

```text
点在人身上 -> 输出这个人的 mask
框住汽车 -> 输出汽车 mask
文本“天空” -> 输出天空区域，前提是模型支持文本或开放词汇能力
```

## 八、实际项目怎么选

| 需求 | 选择 |
|---|---|
| 只需要每个像素属于什么类别 | 语义分割 |
| 需要数清每个独立目标 | 实例分割 |
| 既要背景区域，又要区分前景个体 | 全景分割 |
| 想用点、框、文本交互式抠图或自动标注 | 通用分割 / SAM |
| 医学器官、缺陷区域、遥感地物 | 多数从语义分割开始 |
| 商品、零件、行人、车辆逐个分离 | 实例分割 |
| 自动驾驶完整场景解析 | 全景分割 |

## 九、标注成本对比

| 任务 | 标注成本 | 说明 |
|---|---:|---|
| 图像分类 | 低 | 每张图一个或多个类别 |
| 目标检测 | 中 | 每个目标画 bbox |
| 语义分割 | 高 | 每个像素要有类别 |
| 实例分割 | 高 | 每个目标要单独画 mask |
| 全景分割 | 很高 | 整图像素分类 + thing 实例区分 |
| 通用分割数据 | 很高 | 常依赖大规模 mask、提示和自动标注流程 |

实际项目中，经常会用 SAM 这类模型辅助标注，再人工修正，以降低 mask 标注成本。

## 十、容易混淆的问题

### 1. 语义分割能不能数人数？

不适合。语义分割只知道哪些像素属于 person，不知道每个人的独立身份。人数统计通常需要实例分割或检测。

### 2. 实例分割会不会分割天空和道路？

通常不会。实例分割主要关注可数对象，例如人、车、动物、商品。天空、道路这类 stuff 更适合语义分割或全景分割。

### 3. 全景分割是不是最强？

任务最完整，但不一定总是最合适。它标注成本高、模型复杂、评估和部署也更麻烦。如果项目只需要缺陷区域，用语义分割更直接。

### 4. SAM 是不是语义分割模型？

不是严格意义上的语义分割模型。SAM 是通用可提示分割模型，主要输出 mask，不直接输出固定语义类别。

### 5. YOLOv8-Seg 属于什么分割？

YOLOv8-Seg 主要属于实例分割。它检测目标实例，并为每个实例预测 mask。

## 十一、总结

图像分割的核心是 mask，但不同任务对 mask 的要求不同：

| 任务 | 一句话理解 |
|---|---|
| 语义分割 | 每个像素属于哪个类别 |
| 实例分割 | 每个独立对象的 mask 是什么 |
| 全景分割 | 整张图每个像素是什么，同时区分可数对象 |
| 通用分割 | 根据提示或开放类别生成需要的 mask |

如果刚开始学习，建议顺序是：

```text
语义分割
  -> 实例分割
  -> 全景分割
  -> SAM / 通用分割
```

这样能先理解像素级分类，再理解实例级 mask，最后再看统一分割和大模型分割。
