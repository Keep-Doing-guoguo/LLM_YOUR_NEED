# YOLO 系列结构块讲解

本文集中说明 YOLO 系列中反复出现的 Backbone、Neck 和小模块结构。重点不是复述每个版本的完整网络，而是把常见结构块拆开看：它们怎么连接、解决什么问题、通常出现在 YOLO 的哪个版本中。

## 一、先看 YOLO 网络中的三段结构

YOLO 系列检测器通常可以拆成三部分：

```text
Input Image
  -> Backbone: 提取多层视觉特征
  -> Neck: 融合不同尺度特征
  -> Head: 输出 bbox、objectness、class 或解耦后的分类/回归结果
```

Backbone 负责从图像中提取纹理、边缘、局部形状和高层语义；Neck 负责把浅层的细节信息和深层的语义信息融合；Head 负责把特征转成检测结果。

本文重点解释 Backbone 和 Neck 中的结构块，例如 Darknet、CSP、C3、C2f、ELAN、RepBlock、PANet 等。

## 二、CSP 结构

CSP 是 Cross Stage Partial Network 的缩写，中文可以理解为“跨阶段局部连接”。它最早被大量用于 YOLOv4 的 CSPDarknet53，后续 YOLOv5 的 C3、YOLOv8 的 C2f、YOLO11 的 C2f/CSP-style 结构都可以看作对 CSP 思想的延续。

### 1. CSP 解决什么问题

普通残差堆叠会让全部通道都经过多个 Bottleneck 或 Residual Block。这样表达能力强，但也会带来两个问题：

- 计算量较大；
- 不同路径上可能产生重复梯度信息；
- 网络越深，训练成本和显存成本越高。

CSP 的核心做法是把输入特征按通道拆成两路：

```text
Input
  -> Split
      -> Branch A: 经过若干 Bottleneck / Residual Block
      -> Branch B: 直接跨阶段保留
  -> Concat
  -> 1x1 Conv 融合通道
  -> Output
```

Branch A 负责复杂特征变换，Branch B 保留一部分原始信息并提供更短的梯度路径。最后通过 Concat 和 1x1 Conv 重新融合。

### 2. CSP 的结构特点

| 特点 | 说明 |
|---|---|
| 通道拆分 | 不是所有通道都进入深层堆叠，降低计算冗余 |
| 跨阶段连接 | 一部分特征绕过重计算路径，保留原始信息 |
| Concat 融合 | 两路特征在阶段末尾合并 |
| 1x1 Conv 调整 | 控制输出通道数，压缩或混合特征 |

### 3. CSP 在 YOLO 中的常见变体

| 结构 | 常见版本 | 说明 |
|---|---|---|
| CSPDarknet53 | YOLOv4 | Darknet-53 加入 CSP 分支思想 |
| C3 | YOLOv5 | CSP Bottleneck 的工程化模块 |
| CSPBep / CSPStackRep | YOLOv6 部分模型 | CSP 思想结合重参数化模块 |
| ELAN / E-ELAN | YOLOv7 | 不完全等同 CSP，但同样强调多分支聚合和梯度路径 |
| C2f | YOLOv8、YOLO11 | 更轻的 CSP-like 结构，增强特征复用 |
| RepNCSPELAN / GELAN | YOLOv9 | 结合 CSP、ELAN、重参数化和梯度路径设计 |

## 三、PANet 结构

PANet 是 Path Aggregation Network 的缩写。YOLOv4、YOLOv5 之后的很多 YOLO 版本都使用 PAN/FPN 风格的多尺度融合结构。

### 1. FPN 和 PANet 的区别

FPN 主要做自顶向下融合：

```text
P5 高层语义
  -> 上采样
  -> 与 P4 拼接
  -> 上采样
  -> 与 P3 拼接
```

这样可以把高层语义传给高分辨率特征，帮助小目标检测。

PANet 在 FPN 基础上增加自底向上的路径：

```text
P3 细节特征
  -> 下采样
  -> 与 P4 融合
  -> 下采样
  -> 与 P5 融合
```

这样浅层定位信息也能回流到深层检测特征中。

### 2. PANet 的典型结构

```text
Backbone 输出:
  C3: stride 8,  高分辨率, 适合小目标
  C4: stride 16, 中等分辨率, 适合中目标
  C5: stride 32, 低分辨率, 高语义, 适合大目标

Top-down:
  C5 -> Upsample -> Concat C4 -> Conv Block
     -> Upsample -> Concat C3 -> Conv Block

Bottom-up:
  P3 -> Downsample -> Concat P4 -> Conv Block
     -> Downsample -> Concat P5 -> Conv Block
```

### 3. PANet 的作用

| 作用 | 说明 |
|---|---|
| 融合语义信息 | 高层特征帮助浅层理解目标类别 |
| 融合定位信息 | 浅层特征帮助深层保留边界和位置 |
| 改善小目标检测 | 小目标依赖高分辨率特征和强语义补充 |
| 支持多尺度输出 | 最终通常输出 P3、P4、P5 三个检测尺度 |

### 4. YOLO 中的 PANet 变体

| 结构 | 常见版本 | 说明 |
|---|---|---|
| SPP + PANet | YOLOv4 | SPP 扩感受野，PANet 做多尺度融合 |
| FPN + PAN | YOLOv5 | 常见的上采样、Concat、C3、下采样结构 |
| Rep-PAN | YOLOv6 | 用 RepBlock 替代部分普通卷积块，偏部署效率 |
| ELAN-PAN | YOLOv7 | 融合路径中使用 ELAN 类模块 |
| PAN-FPN + C2f | YOLOv8、YOLO11 | Neck 中继续使用 C2f/CSP-like 融合模块 |

## 四、YOLOv1 Backbone 小模块

YOLOv1 使用早期 Darknet 风格的卷积主干。它没有现代 YOLO 中的 CSP、PANet、SPP 或解耦头，整体更像一个卷积分类网络后接检测回归层。

### 1. Conv + Leaky ReLU

YOLOv1 的基础单元是卷积和 Leaky ReLU：

```text
Input
  -> Conv
  -> Leaky ReLU
  -> Output
```

1x1 卷积常用于压缩通道，3x3 卷积用于提取空间特征。

### 2. MaxPool 下采样

YOLOv1 主要通过 MaxPool 降低特征图分辨率：

```text
Feature Map
  -> MaxPool 2x2 / 2
  -> Resolution / 2
```

这种设计简单直接，但浅层和深层之间没有现代多尺度融合，所以 YOLOv1 对小目标和密集目标不够友好。

## 五、YOLOv2 Backbone 小模块：Darknet-19

YOLOv2 使用 Darknet-19 作为主干网络。Darknet-19 比 YOLOv1 的主干更规整，也更适合分类预训练和检测迁移。

### 1. Darknet-19 基础结构

Darknet-19 主要由 3x3 Conv、1x1 Conv 和 MaxPool 组成：

```text
Conv 3x3
  -> MaxPool
  -> Conv 3x3
  -> MaxPool
  -> Conv 3x3
  -> Conv 1x1
  -> Conv 3x3
  -> ...
```

其中 1x1 Conv 的作用是压缩或调整通道，减少后续 3x3 Conv 的计算量。

### 2. Passthrough / Reorg

YOLOv2 引入 passthrough 层，把较浅层的高分辨率特征重排后拼接到深层特征上：

```text
Shallow Feature: 26x26xC
  -> Reorg / Space-to-depth
  -> 13x13x4C
  -> Concat Deep Feature
```

它的作用类似早期的特征融合：让检测头既能看到深层语义，也能看到浅层细节。

## 六、YOLOv3 Backbone 小模块：Darknet-53

YOLOv3 使用 Darknet-53，核心是残差结构。它比 Darknet-19 更深，并且通过残差连接改善深层网络训练。

### 1. Residual Block

Darknet-53 的基本残差块通常是：

```text
Input
  -> Conv 1x1
  -> Conv 3x3
  -> Add Input
  -> Output
```

1x1 Conv 用于压缩通道，3x3 Conv 用于空间特征提取，Add 连接保留原输入并改善梯度传播。

### 2. Darknet-53 阶段结构

Darknet-53 通常按不同分辨率阶段堆叠残差块：

| 阶段 | 分辨率变化 | 作用 |
|---|---|---|
| Stem | 初始卷积 | 提取低级边缘纹理 |
| Stage 1/2 | 下采样 + 少量残差块 | 建立局部特征 |
| Stage 3/4 | 下采样 + 多个残差块 | 提取中层语义 |
| Stage 5 | stride 32 深层特征 | 提取高层语义 |

YOLOv3 会从 Darknet-53 中取三个尺度的特征用于检测，通常对应 stride 8、16、32。

## 七、YOLOv3-SPP 小模块：SPP

YOLOv3-SPP 在 YOLOv3 的 Darknet-53 后面加入 SPP 模块。它通常放在最深层特征，也就是 stride 32 的高语义特征附近。

### 1. SPP 结构

YOLO 中的 SPP 通常不是标准分类网络里的固定长度池化，而是多尺度最大池化后拼接：

```text
Input Feature
  -> MaxPool 5x5
  -> MaxPool 9x9
  -> MaxPool 13x13
  -> Concat(Input, Pool5, Pool9, Pool13)
  -> Output
```

池化一般使用合适 padding，使输出空间尺寸不变。

### 2. SPP 的作用

| 作用 | 说明 |
|---|---|
| 扩大感受野 | 不继续下采样，也能看到更大范围上下文 |
| 增强高层语义 | 对大目标和复杂背景更有帮助 |
| 结构简单 | 只用 MaxPool 和 Concat，部署相对容易 |

## 八、YOLOv4 Backbone 小模块：CSPDarknet53

YOLOv4 的主干是 CSPDarknet53，可以理解为 Darknet-53 加入 CSP 思想后的版本。

### 1. CSPDarknet Stage

一个典型 CSPDarknet 阶段可以写成：

```text
Input
  -> Downsample Conv
  -> Split
      -> Branch A: Residual Block x N
      -> Branch B: Shortcut Conv
  -> Concat
  -> Conv Fuse
  -> Output
```

它保留了 Darknet 的残差特征提取能力，同时减少重复计算。

### 2. Mish / Leaky ReLU

YOLOv4 中常见 Mish 激活：

```text
Mish(x) = x * tanh(softplus(x))
```

Mish 相比 Leaky ReLU 更平滑，但部署成本更高。后续很多工程实现会继续使用 Leaky ReLU 或 SiLU。

### 3. SPP + PANet

YOLOv4 的 Neck 常见组合是：

```text
CSPDarknet53
  -> SPP
  -> PANet
  -> YOLO Head
```

SPP 增强最深层语义，PANet 融合 P3/P4/P5 多尺度特征。

## 九、YOLOv5 Backbone 小模块：Focus、C3、SPPF

YOLOv5 的主干通常被称为 CSPDarknet 的轻量化工程版本。它常见模块包括 Focus、Conv、C3 和 SPPF。

### 1. Focus

早期 YOLOv5 使用 Focus 做空间到通道的重排：

```text
Input: H x W x C
  -> 切片取四个子图
  -> Concat on Channel
  -> H/2 x W/2 x 4C
  -> Conv
```

它的作用是快速下采样并保留局部信息。后续版本中 Focus 常被普通 stride=2 Conv 替代，原因是普通卷积在部署框架中更友好。

### 2. C3

C3 是 YOLOv5 中最重要的 CSP-style 模块：

```text
Input
  -> Branch A: Conv -> Bottleneck x N
  -> Branch B: Conv
  -> Concat
  -> Conv
  -> Output
```

C3 中的 Bottleneck 通常是：

```text
Input
  -> Conv 1x1
  -> Conv 3x3
  -> Add Input, if shortcut=True
```

Backbone 中的 C3 多数保留 shortcut，Neck 中的 C3 有些实现会关闭 shortcut。

### 3. SPPF

SPPF 是 Spatial Pyramid Pooling - Fast 的缩写。它用连续的 5x5 MaxPool 近似原 SPP 中 5、9、13 的多尺度池化：

```text
Input
  -> MaxPool 5x5 -> y1
  -> MaxPool 5x5(y1) -> y2
  -> MaxPool 5x5(y2) -> y3
  -> Concat(Input, y1, y2, y3)
  -> Conv
```

SPPF 比并行 SPP 更快，结构更简单。

## 十、YOLOv6 Backbone 小模块：RepVGG、EfficientRep、Rep-PAN

YOLOv6 更强调部署效率，大量使用重参数化结构。训练时是多分支，推理时融合成单个 3x3 Conv。

### 1. RepVGG Block

训练阶段：

```text
Input
  -> Branch A: Conv 3x3 + BN
  -> Branch B: Conv 1x1 + BN
  -> Branch C: Identity + BN
  -> Add
  -> Activation
```

推理阶段：

```text
Input
  -> Single Conv 3x3
  -> Activation
```

重参数化会把 3x3、1x1、Identity 分支的权重和 BN 参数融合到一个 3x3 卷积中。这样训练时表达能力强，推理时结构简单。

### 2. EfficientRep

EfficientRep Backbone 用 RepBlock 堆叠形成不同阶段：

```text
Input
  -> RepConv / RepBlock
  -> Downsample
  -> RepBlock x N
  -> Downsample
  -> RepBlock x N
```

它相比 CSP-style backbone 更偏向推理友好，尤其适合 TensorRT 等部署场景。

### 3. Rep-PAN

Rep-PAN 是 PAN 结构的重参数化版本：

```text
Backbone Features
  -> Top-down PAN/FPN fusion
  -> RepBlock
  -> Bottom-up PAN fusion
  -> RepBlock
```

本质仍是多尺度融合，只是把融合后的卷积块换成更适合部署的 RepBlock。

## 十一、YOLOv7 Backbone 小模块：ELAN、E-ELAN、MPConv

YOLOv7 的核心结构是 ELAN / E-ELAN。它的目标是让网络加深时仍保持稳定、高效的梯度路径。

### 1. ELAN

ELAN 可以理解为多分支卷积堆叠与聚合：

```text
Input
  -> Branch 1: Conv
  -> Branch 2: Conv -> Conv
  -> Branch 3: Conv -> Conv -> Conv
  -> Concat
  -> Conv Fuse
```

不同分支有不同深度，Concat 后融合多层次特征。

### 2. E-ELAN

E-ELAN 在 ELAN 基础上进一步扩展分支和通道组织方式：

```text
Input
  -> Expand Channels
  -> 多组 Conv 分支
  -> Shuffle / Merge
  -> Concat
  -> Fuse
```

它强调在不破坏原有梯度路径的前提下提升特征表达能力。

### 3. MPConv

YOLOv7 中常见 MPConv 下采样结构：

```text
Input
  -> Branch A: MaxPool -> Conv
  -> Branch B: Conv stride=2
  -> Concat
```

它把池化下采样和卷积下采样结合起来，兼顾局部强响应和可学习特征变换。

## 十二、YOLOv8 Backbone 小模块：C2f

YOLOv8 使用 C2f 作为核心模块。C2f 可以看作 C3 的进一步简化和增强特征复用版本。

### 1. C2f 结构

```text
Input
  -> Conv
  -> Split into two parts
      -> Part 1: 直接保留
      -> Part 2: Bottleneck 1 -> Bottleneck 2 -> ... -> Bottleneck N
  -> Concat(Part 1, Part 2, each Bottleneck output)
  -> Conv Fuse
  -> Output
```

和 C3 相比，C2f 会把中间 Bottleneck 的输出也参与拼接，因此特征复用更充分。

### 2. C2f 的作用

| 作用 | 说明 |
|---|---|
| 增强梯度流 | 多个中间输出直接参与融合 |
| 减少冗余 | 保留 CSP 的局部计算思想 |
| 易扩展 | 通过改变 Bottleneck 数量适配 n/s/m/l/x 模型 |

## 十三、YOLOv9 Backbone 小模块：GELAN、RepNCSPELAN、PGI

YOLOv9 的结构重点是 GELAN 和 PGI。PGI 更偏训练信息路径，GELAN 是更直接的网络结构。

### 1. GELAN

GELAN 可以理解为 Generalized ELAN，它继承 ELAN 的多分支聚合思想，同时结合 CSP 类结构：

```text
Input
  -> Split / Expand
  -> 多个卷积分支或 Rep 分支
  -> Concat
  -> Fuse
  -> Output
```

它的目标是保持较好的梯度流，同时提升参数利用率。

### 2. RepNCSPELAN

RepNCSPELAN 名字可以拆开理解：

| 部分 | 含义 |
|---|---|
| Rep | 使用重参数化卷积块 |
| NCSP | CSP 类分支结构 |
| ELAN | 多分支特征聚合 |

结构上可以概括为：

```text
Input
  -> CSP-style Split
  -> RepConv / Bottleneck branches
  -> ELAN-style Concat
  -> Conv Fuse
```

它把 YOLOv5 的 CSP、YOLOv6 的 Rep、YOLOv7 的 ELAN 思想融合到一个更通用的结构里。

### 3. PGI

PGI 是 Programmable Gradient Information，主要用于改善深层网络训练中的信息瓶颈和梯度传递。它不是简单的推理模块，更多是训练阶段的信息路径设计。

## 十四、YOLOv10 Backbone 小模块：C2f/CSP 类结构与 PSA

YOLOv10 强调 NMS-free 检测和端到端部署。Backbone 仍以卷积和 CSP/C2f 类模块为基础，同时引入效率相关结构。

### 1. C2f / CSP-style Block

YOLOv10 中的主体特征提取仍可理解为：

```text
Input
  -> Conv Downsample
  -> C2f / CSP-style Block
  -> Conv Downsample
  -> C2f / CSP-style Block
```

这些结构和 YOLOv8 的 C2f 思路接近，用于兼顾精度、速度和梯度流。

### 2. PSA

PSA 通常指 Partial Self-Attention 或类似的部分注意力设计。它不是对全通道、全特征都做昂贵注意力，而是只对部分通道或部分路径加入注意力：

```text
Input
  -> Split
      -> Branch A: Attention
      -> Branch B: Conv / Identity
  -> Concat / Fuse
```

这样可以在较低开销下增强全局关系建模。

## 十五、YOLO11 Backbone 小模块：改进 C2f/CSP-style

YOLO11 继续使用 C2f/CSP-style 的主干思路，整体目标是更高效地提取局部纹理和高层语义。

### 1. 改进型 C2f

结构上仍围绕分支、瓶颈和拼接：

```text
Input
  -> Conv
  -> Split
  -> Bottleneck sequence
  -> Concat intermediate features
  -> Conv Fuse
```

与 YOLOv8 相比，YOLO11 更强调模块组合和不同任务上的统一部署，Backbone 仍然是轻量卷积块和 CSP-like 结构的组合。

### 2. PAN/FPN Neck

YOLO11 的 Neck 仍是 PAN/FPN 风格：

```text
C5 -> Upsample -> Concat C4 -> Block
   -> Upsample -> Concat C3 -> Block
P3 -> Downsample -> Concat P4 -> Block
   -> Downsample -> Concat P5 -> Block
```

核心逻辑和 YOLOv5/YOLOv8 一脉相承。

## 十六、YOLOv12 Backbone 小模块：CNN + 高效注意力

YOLOv12 可以理解为在 CNN 主干中加入更高效的注意力模块。它不是完全抛弃卷积，而是在局部卷积特征基础上补充全局建模能力。

### 1. CNN Block

基础路径仍是卷积下采样和卷积块堆叠：

```text
Input
  -> Conv Downsample
  -> Conv Block x N
  -> Output Feature
```

卷积负责高效提取局部纹理、边缘和形状。

### 2. Efficient Attention Block

高效注意力模块通常会避免标准 Transformer 那种高开销全局注意力，常见思路是局部窗口、通道压缩、部分通道注意力或线性复杂度注意力：

```text
Input
  -> Conv / Norm
  -> Efficient Attention
  -> FFN or Conv Fuse
  -> Output
```

它的作用是补充长距离依赖，让模型更好理解全局结构和复杂遮挡关系。

## 十七、YOLOv13 Backbone 小模块：卷积 + 超图增强模块

YOLOv13 的文档中强调 hypergraph-enhanced perception，可以理解为在传统 CNN 特征上加入更强的关系建模模块。

### 1. 普通卷积主干

Backbone 仍保留 YOLO 的基本范式：

```text
Input
  -> Conv Downsample
  -> Conv / CSP-like Blocks
  -> Multi-scale Features
```

### 2. Hypergraph-enhanced Module

超图模块关注的不只是两两像素或两两区域关系，而是更高阶的组关系：

```text
Feature Map
  -> 构建区域/语义节点
  -> 建立高阶关系
  -> 聚合关系特征
  -> Fuse back to CNN feature
```

它的目标是让模型在复杂场景中更好理解多个目标、背景区域和语义上下文之间的关系。

## 十九、学习这些结构块时的主线

可以按下面这条线理解 YOLO Backbone 的演进：

```text
普通卷积堆叠
  -> 1x1/3x3 交替降低计算
  -> Residual Block 解决深层训练
  -> CSP 减少冗余计算并改善梯度
  -> RepBlock 兼顾训练表达和推理速度
  -> ELAN/C2f/GELAN 强化多分支特征复用
  -> Attention/Hypergraph 补充全局和高阶关系建模
```

Neck 的演进可以按下面这条线理解：

```text
单尺度检测
  -> Passthrough 浅深层拼接
  -> FPN 自顶向下语义融合
  -> PANet 增加自底向上定位回流
  -> Rep-PAN / C2f-PAN / ELAN-PAN 提升效率和表达能力
```

理解 YOLO 的结构块时，不需要死记每个版本的所有层数。更重要的是判断一个模块在解决什么问题：是为了降计算、扩感受野、改善梯度流、增强特征复用，还是为了部署时更快。
