# 图文对齐机制详解

图文对齐是多模态模型的起点。它要解决的问题是：

```text
一张图片和一句文字，模型怎么知道它们描述的是同一个语义？
```

代表模型是 CLIP 和 ALIGN。

![CLIP 对比学习](./assets/clip-contrastive.svg)

## 一、图文对齐的基本结构

图文对齐模型通常有两个编码器：

```text
Image
  -> Image Encoder
  -> image embedding

Text
  -> Text Encoder
  -> text embedding
```

两个 embedding 会被映射到同一个向量空间。训练目标是让匹配的图文对距离更近，不匹配的图文对距离更远。

## 二、正样本和负样本

一个 batch 中有 N 对图文：

```text
(image_1, text_1)
(image_2, text_2)
(image_3, text_3)
...
```

其中 `image_i` 和 `text_i` 是正样本对。

`image_i` 和其他 `text_j` 则是负样本对。

相似度矩阵可以理解为：

```text
          text1  text2  text3
image1     正     负     负
image2     负     正     负
image3     负     负     正
```

训练时希望对角线分数高，非对角线分数低。

## 三、InfoNCE / Contrastive Loss

CLIP 常用对比学习目标。对每张图片来说，正确文本应该在所有文本候选里概率最高。

反过来，对每段文本来说，正确图片也应该概率最高。

```text
image -> text classification
text  -> image classification
```

所以 CLIP 的 loss 通常是双向的：

```text
loss = image_to_text_loss + text_to_image_loss
```

## 四、图文对齐带来的能力

图文对齐让模型具备开放词汇能力。

例如做图像分类时，不需要专门训练分类头，可以构造文本提示：

```text
a photo of a cat
a photo of a dog
a photo of a car
```

然后计算图片 embedding 和这些文本 embedding 的相似度。

谁相似度最高，就预测哪个类别。

## 五、图文对齐的局限

CLIP 这类模型很擅长“相似度判断”，但不等于能进行复杂对话。

局限包括：

- 不擅长生成长回答；
- 细粒度 OCR 能力有限；
- 定位能力不强；
- 不能天然输出 bbox；
- 复杂推理能力依赖后续 LLM 接入。

所以后续才出现了 BLIP-2、LLaVA、Qwen-VL 这类把视觉特征接入大语言模型的路线。
