# 多模态训练任务与损失函数

多模态能力不是靠单一任务训练出来的。一个 VLM 通常需要图文对齐、图像描述、视觉问答、OCR、Grounding、指令微调等任务共同塑造。

![多模态训练任务](./assets/multimodal-training-tasks.svg)

## 一、ITC：Image-Text Contrastive

ITC 是图文对比学习。

目标：

```text
匹配图文对更近
不匹配图文对更远
```

代表模型：

```text
CLIP
BLIP
ALIGN
```

它解决的是图像和文本的全局语义对齐问题。

## 二、ITM：Image-Text Matching

ITM 是判断图像和文本是否匹配。

输入：

```text
image + text
```

输出：

```text
matched / not matched
```

相比 ITC，ITM 通常会使用融合后的图文表示，更关注细粒度匹配。

## 三、Caption / Language Modeling

图像描述任务让模型根据图片生成文字：

```text
Image -> "一只猫坐在沙发上"
```

训练时通常使用语言模型损失：

```text
预测下一个 token
```

它让模型学会把视觉信息转成自然语言。

## 四、VQA：Visual Question Answering

VQA 输入图片和问题，输出答案。

```text
Image + "图中有几个人？" -> "三个人"
```

它要求模型不仅看图，还要理解问题重点。

VQA 对模型的要求比 caption 更高，因为模型需要选择性关注图像区域。

## 五、OCR 训练

OCR 任务让模型读取图中文字。

常见训练样本：

```text
Image + "图片中的文字是什么？" -> "..."
```

OCR 对数据和分辨率很敏感。截图、文档、表格、票据、菜单等数据对提升 OCR 能力很重要。

## 六、Grounding 训练

Grounding 是文本短语和图像区域的对齐。

训练样本可能是：

```text
Image + "找到红色汽车" -> box coordinates
```

或者：

```text
Image + box -> "红色汽车"
```

它让模型具备定位能力，而不只是生成描述。

## 七、多模态指令微调

SFT 阶段把模型训练成对话助手。

样本形式：

```text
用户: <image> 请描述这张图。
助手: ...
```

或者：

```text
用户: <image> 图中左上角写了什么？
助手: ...
```

指令微调决定模型是否能按人类提问方式稳定回答。

## 八、视频任务

视频任务比图片任务多了时间维度。

模型要理解：

- 动作顺序；
- 事件变化；
- 物体运动；
- 多帧之间的一致性。

训练数据可以是：

```text
video + question -> answer
video + instruction -> summary
```

视频任务的难点是 token 成本高，抽帧策略会直接影响模型看到的信息。
