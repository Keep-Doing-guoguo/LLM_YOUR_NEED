# 多模态模型发展阶段总览

| 阶段               | 模型代表                        | 时间        | 说明                                                         |
|--------------------|---------------------------------|-------------|--------------------------------------------------------------|
| 基础对齐模型       | CLIP, ALIGN                     | 2021        | 大规模图文对比学习，统一视觉和语言的嵌入空间                |
| 通用图文理解模型   | BLIP, Florence                  | 2022        | 图文互理解，具备 Caption / VQA 能力                          |
| 图文连接 LLM       | BLIP-2                          | 2023        | 引入 Q-former，支持连接大语言模型（如 Vicuna）              |
| 多模态对话         | MiniGPT-4, LLaVA                | 2023        | 基于图像编码器 + LLM 实现图文对话推理                       |
| 高阶多模态理解     | CogVLM, Gemini, Emu             | 2023–2024   | 更强视觉感知能力，支持图文理解、问答、多跳推理              |
| 应用系统层         | 多模态 RAG, 多模态 Agent       | 2024 以后   | 结合检索 / 审查 / 问诊 / 数据智能等场景                     |
